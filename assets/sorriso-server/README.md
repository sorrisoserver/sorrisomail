# Recursos oficiais Sorriso Server Mail

Coloque neste diretório a imagem oficial fornecida pelo proprietário com o nome exato `logo-oficial.jpeg`.

O workflow `Sorriso Server Mail - Branded Windows Preview` usa esse arquivo para gerar ícones PNG e ICO durante a compilação. Não utilizar logos substitutas ou imagens geradas artificialmente.

Após os testes, revisar caminhos de dados, atualizações, instalador e assinaturas antes de qualquer distribuição.
